# 历史研究汇总

本目录保存作者授权公开的七个研究模型汇总、模型 3 年度样本外结果和 11 条汇总净值曲线，按项目 MIT 许可证发布。

- `model*_summary.csv`：资产范围、样本期间、成本情景、验证状态和主要指标。
- `model3_annual_oos.csv`：保留负年度与不完整年度的样本外结果。
- `curves/model*--*.json`：交易日、净值、回撤，以及原始汇总来源的校验值。

这些文件来自既有历史研究批次，不是随应用启动而重跑的结果。模型 2、6 保留未通过状态。目录不含原始市场行情、模型权重、证券级持仓或账户资料。

页面按模型和成本情景加载曲线，加载时检查日期、净值与回撤关系。研究说明见 [计算口径](../docs/methodology.md)。
