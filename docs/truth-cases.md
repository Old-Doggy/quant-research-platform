# 研究验收样本

预期值位于 `tests/fixtures/research_truth/cases.json`。所有六个小账本均为合成测试，金额、数量与日期专为手算设计，不进入默认行情、作品页或研究结论。

| 样本 | 独立预期 | 接入任务 |
|---|---|---|
| 分红 | 100股从10元除息至9.5元，应收50元；现金100元、权益1100元不变；到账后现金150元、应收清零 | T10 |
| 送股 | 100股每股送0.2股，数量变120，成本1200不变；20股上市前不可卖 | T11 |
| 停牌 | 100股按最后10元估值，加现金50元，权益1050；买入无成交；缺数据不能当停牌 | T13 |
| 退市 | 历史查询仍含当时上市证券；退出后不可成交；没有退出价不能按0元结算 | T17/T35 |
| 财务更正 | 首次公告ROE为8，更正后6；公告前未知，更正前截面仍为8，旧实验不改写 | T08/T34 |
| ETF规则 | 股票ETF当日买入部分不可当日卖；已验证T+0类别按其规则；未知类型不能默认T+0 | T12/T51 |

当前测试核对样本结构、手算恒等式与预期值，**不表示公司行为、PIT或ETF新机制已实现**。后续各任务须让实际引擎读取同样输入并核对同样答案，不得把引擎运行结果反写成预期值。

真实事件核对候选记录来自Tushare官方分红文档的600848.SH送股示例（登记1995-06-06，除权1995-06-07，每股送0.10股）。它只证明供应商文档中有该示例；M2需另核交易所/公司公告、上市日期与实际行情，再升级为真实事件验收样本。文档示例不能代替完整历史数据。

分红税在小账本明确设为0。正式研究要单独定义税费、登记持仓、应收可用性、送股上市日期、退出与公司行为更正；未知情况不得套用这个简化假设。
