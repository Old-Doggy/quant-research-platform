# 使用指南

## 第一次打开

默认进入“看盘”，使用内置合成数据。先观察 K 线、指标与近期交易概览，再点“提交研究”查看模板策略结果。合成数据只用于体验功能，代码以 `SYNTH_` 或 `DEMO_` 开头。

侧栏固定显示七个工作区。研究设置按常用项和高级项展开；修改参数后需要重新提交，完成的结果对应提交时的参数。

## 导入自己的数据

1. 进入“数据”，打开“数据来源与设置”，选择“文件导入”。
2. 上传 CSV、Excel 或 Parquet，完成字段映射并确认预览。
3. 检查日期、重复记录、价格关系和成交量，处理异常后登记数据版本。
4. 使用侧栏的登记数据选项，将该版本用于因子、策略或组合研究。

数据格式与下载方法见 [数据指南](data.md)。上传暂存、登记信息和研究日志保存在本机 `output/`，不会提交到 Git。可以用 `PORTFOLIO_STATE_DIR` 指定其他保存位置。

## 看盘与策略

“看盘”支持日、周、月 K 线，滚动、缩放、十字光标、指标切换和成交事件定位。日期范围只改变当前观察区间；图表缩放不改变回测计算。

趋势跟踪、均值回归可直接用合成价量样例运行；质量动量需要ROE/PB及其可用时点，缺少时不开放运行。“作品”中的七个历史模型是另一组研究案例，不能把模板回测结果当作这七个模型的重新训练结果。

策略结果分为净值表现、买卖事件、成本与参数、研究记录。净值与回撤共用日期，点击买卖标记查看信号与执行记录；成本图显示每日及累计换手成本。净值、事件和成本可切表格并下载完整数据，缩放和分页不改变计算。

单股模板按持仓比例计算收益，事件数量为单位化记录。组合研究使用资金、股数、现金和费用账本，两者的现金表不能直接互换。

## 因子与组合

因子分析需要多个标的在同一天的有效数据。先选因子和持有跨度，再查看分布、Rank IC 与分组差异。分组未来收益描述因子关联，不是已经扣除费用的组合净值。

组合研究可设置权重与现金，查看调仓、成交、持仓和收益贡献。不同标的的日期不齐时，应明确对齐会话或使用界面允许的共同会话处理，不应补造停牌日交易。

## 保存结果

本地研究任务成功后保存结果包，可在“实验”的历史结果中检索、打开和比较；失败/取消记录保留任务状态。结果仍对应提交时的数据与参数，更改页面设置不会改写历史包。

可下载完整私有ZIP，或使用[备份恢复](recovery-runbook.md)保存选定快照、结果和用户状态。复算需要原始输入及相同计算版本；版本不符会显示具体原因。旧摘要格式单独保留，不能替代完整输入。尚未提交的草案和内存页面状态不保证重启恢复。

## 作品

先选择模型，再查看方法、数据时点、验证和净值。成本场景可切换；净值与回撤共用日期。已公开的结果位于 `public_evidence/`，其中不含逐股仓位或账户记录。
