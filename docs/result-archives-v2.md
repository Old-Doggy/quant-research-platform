# 本地研究归档

实验 → 单次结果 → 本次参数与运行记录，点击“准备完整归档”后下载ZIP。压缩包保存原运行清单、原始输入、结果数组与曲线CSV，保留任务身份和保存时间。仅在点击后生成，切换结果会丢弃上一份下载缓存。

实验页的“导入研究归档”可将ZIP导入本地结果库。导入逐文件核对，拒绝未知路径、重复文件、内容损坏或超过容量预算的包；相同任务与相同内容可重复导入，不同内容不能覆盖已有结果。索引在完整文件校验后登记。

完整包含研究原料、持仓与订单，仅供本地迁移，不等同公开摘要。原数据来源和授权继续适用。公开模式不提供私有归档入口。压缩前文件合计与上传包均受64 MB预算限制，较大的资料使用选定备份恢复入口。

导入后可查看原图、表格和参数。保存了复算输入且计算及依赖版本一致时，可点击“重新计算并核对”。版本不一致会停止复算，不影响读取原始结果。

旧版策略JSON、因子ZIP与组合摘要继续保留各自格式；新入口迁移结果库的完整运行，不将旧版摘要自动升级为可复算结果。
