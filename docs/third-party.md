# 许可证与第三方资源

项目代码、文档、合成示例与作者授权公开的历史汇总采用根目录 MIT 许可证。MIT 不改变外部行情服务的数据条款。

K 线图使用 Lightweight Charts 4.2.0，来源为 TradingView。Apache-2.0 许可证、NOTICE 和版本校验记录位于 `portfolio_app/chart_assets/`，页面保留 TradingView 署名。完整条款见其中的 `LICENSE.txt` 和 `NOTICE.txt`。

Python 依赖通过 `requirements.txt` 安装，不将依赖源码复制到仓库。Streamlit、Plotly、pandas、NumPy、PyArrow 等依赖遵循各自分发版本的许可证。
