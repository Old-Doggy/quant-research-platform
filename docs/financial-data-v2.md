# 财务数据与可得时间

## 免费三表与页面（2026-11-16）

数据中心增加“财务”页，可按证券和季度末获取新浪三张报表，保存完整JSON原始响应、标准字段、公告日、币种、合并类型、来源更新时间及本机观察时间。接口为新浪 `CompanyFinanceService.getFinanceReport2022`，字段依据当前AKShare同名采集函数核对，直接请求不增加应用依赖。单证券最多12期的页面请求按表依次执行；缺期保留partial，1000条边界拒绝完整，不做静默分页猜测。

两只实测证券为600000.SH与688001.SH，各9个报告期（2024-09至2026-09），三表共54条报告。银行和普通企业的归母利润/归母权益使用不同来源代码，分别映射；同义字段冲突拒绝。初次探测缺映射的私有批次保留，新批次修正字段，不覆盖旧数据。

单位证据来自同一来源的[600000利润表](https://vip.stock.finance.sina.com.cn/corp/go.php/vFD_ProfitStatement/stockid/600000/ctrl/2025/displaytype/4.phtml)、资产负债表、现金流量表及688001对应页面。网页明确“万元”，API金额按元保存；2025年600000收入173964000000元、归母利润50017000000元与网页乘10000一致，EPS仍为1.52元/股。688001网页保留两位万元，换算误差在50元显示精度内（现金流最大49.87元）；此核对说明单位与映射，不是独立上游对账。明细保存在私有 output/financial-sina-unit-evidence.json。

页面以收入、归母利润、经营现金流、总资产四图展示，统一亿元；可切累计、单季度、TTM及表格，年报范围可选，下载与展示同源。累计差分只用于收入/利润/现金流，资产保留期末值；缺基期不补零。浏览模式选择最新观察版本，并保留输入版本身份，不能作为历史as-of能力证明。未核验单位的Tushare数据只展示来源值，不混到新浪金额图。

向前观察查询与TTM服务增加显式provider选择，默认仍为Tushare，两来源不合并取最新。新浪并不保留完整修订档案，同公告日不同数值仍拒绝推定版本顺序；当日抓取不可进入当日或过去的研究截面。估值分位、同业比较、财务因子、完整历史PIT及后台日更仍待接入。

## Tushare与时点机制

当前开发版按单只证券、明确季度末报告期采集Tushare利润表、资产负债表、现金流量表及财务指标。普通接口与VIP权限分开，不在代码中自动切到付费接口。每报告期独立请求；达到保守上限即拒绝登记完整，缺报告期保留partial。原始响应、公告日、实际公告日、报告类型、更新标记、抓取时间和数值版本均保留，不按证券/报告期覆盖旧行。

资料依据：Tushare[利润表](https://tushare.pro/document/2?doc_id=33)、[资产负债表](https://tushare.pro/document/2?doc_id=36)、[现金流量表](https://tushare.pro/document/2?doc_id=44)、[财务指标](https://tushare.pro/document/2?doc_id=79)，2026-11-15核对。财务指标文档说明单次100行；三表当前页面未给出可一概使用的固定行数上限，因此代码对单报告期统一采用100行保守拒绝边界，不将其称为接口官方上限。日期过滤语义不同，统一只用明确period；不混用公告日期区间和报告期区间。

各表分开保存。合并累计表、合并单季表、调整表和母公司表不混加。原始金额和比率保持来源值，尚未确认的单位不自动转成百分数/万元，也不能接估值公式。取值缺失保持空，不填零。版本由来源日期、类型、更新标记和内容确定；再次采集相同记录保留观察批次，版本本身不变。

目前历史查询只实现保守的向前观察：公告日/实际公告日和本机首次观察日均已过去后，在下一实际交易日可用。没有发布时间时不推定当天开盘即可使用。今天下载的历史财报不能凭旧ann_date进入过去的回测；即便源含update_flag，也不足以证明保留了完整历史版本和更正发布时间。同一可得日多个不同版本不能凭“最新抓取”或排序猜更正顺序，会要求核对。

本机未配置Tushare token，所以三表真实样本及权限尚未验收，页面不会宣称已具备完整PIT财务能力。当前为数据服务与合成真值检查；TTM/季度转换、ROE/PB、真实公告与证券页接入按后续子项分别验收。

累计报表转换已提供独立服务：合并累计类型1的可加总收入/利润/现金流，TTM=本期累计+上年全年−上年同期累计；第四季度末直接用年报。单季度=本期累计−同年上季度累计，第一季度直接取本期。每个输入分别按同一as-of重新选当时已知版本，并返回其批次及版本，后来的更正不倒灌。缺期/缺值返回不可用，不补零；EPS、ROE、资产负债存量、非人民币元单位不套该公式。来源金额单位尚待真实核对，因此调用方必须明确确认单位为CNY；目前没有默认连接用户研究入口。
