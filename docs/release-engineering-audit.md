## 已知限制与退出条件

- 现有免费行情快照可用于浏览和筛选。进入真实研究仍须满足公司行为、交易状态、规则和数据可用时点等条件。Tushare 权限和无人值守的系统调度、休眠唤醒尚未做实测。
- 四组测试各有一条无效日期样本触发的 pandas 解析警告。Edge 的九条警告来自 Streamlit 组件的 iframe 配置。Ruff 报告集中在三个工作区运行时注入的名称及一处局部类型注解。此前代表场景的组合切页 p95 为 443.2 ms，低于 592.8 ms 回归上限，高于 300 ms 优化目标。

- 连续更新补齐其余九个真实交易日并核对统计、缺口和补抓结果后，进入主分支、正式标签和远端启动验收。执行步骤见[发布检查](release-checklist-v2.md)。
