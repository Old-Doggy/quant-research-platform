# 研究计算口径

## 数据质量

检查日期解析、顺序、重复键、非有限价格、非正价格、OHLC 关系与负成交活动。标准化过程中移除的异常行会保留审计计数；不能以“导入成功”代替质量通过。

## 信号与成交

交互模板包括趋势跟踪、均值回归和质量动量。信号基于当前及历史数据，模拟持仓至少滞后一个交易会话。次日收盘执行时，入场当日不赚取此前的收盘到收盘收益，退出当日保留持有期间收益；次日开盘使用对应开盘价格区分入场、持有和退出。

成本按换手计算，滑点使用显式参数。图中的买卖标记来自同一份模拟事件记录。历史日线假设不能证明订单在真实市场的对应价格成交。

质量动量要求有效 ROE/PB；缺失值不会通过筛选。部分历史基本面的可用时点未外部认证，不能把它们的模板结果作为已完成 PIT 验证的策略表现。

## 收益与风险

净值由每日净收益连乘。最大回撤以初始净值 1 和历史高点为基准，包含首日损失。交互研究默认一年 252 个交易会话，夏普使用年化平均日收益除以年化波动，无风险利率为 0；零波动时不返回无限夏普。

“作品”的历史模型保留原研究批次，原批次的无风险利率、标准差自由度和成本情景可能不同，不能直接组成收益排行榜。曲线 JSON 保存交易日、净值和回撤；汇总指标来自已经核对的研究摘要。汇总不含模型训练数据、权重或逐股成交，因此不能独立重训原模型。

## 因子分析

按交易日计算标的间的 Rank IC，要求足够的有效横截面样本。预热期和未成熟标签保留缺失。多日未来收益重叠，分组平均未来收益是描述统计，不能直接等同可交易组合净值或独立样本显著性。

## 组合与验证

组合明确记录目标权重、现金、交易日期、市场规则和执行成本。数据日期不齐时需要显式对齐，不以填充价格创造可交易会话。账本口径保持现金加持仓市值等于账户权益。

研究提供时间切分、purge / embargo、测试段锁定和参数比较。相关检查约束程序使用已声明的数据，不能凭缺失的公告时间、历史成分或公司行为来源证明没有前视和存续偏差。

## 历史作品

七个模型对应不同资产、期间和验证设计；11 条公开曲线保留原成本分层。模型 2 和 6 的研究门槛未通过状态保留，模型 7 的选择验证、历史本地回测与运行状态分别展示。运行状态不提供收益曲线。
