# 证券交易规则

研究账本可接收证券级规则表，按证券和研究日期选择唯一记录。每条记录包含市场、类别、有效期、整手、T+约束、最小报价、涨跌幅、卖出税率、来源和支持状态；规则内容进入结果配置、输入指纹与计算清单。

实际执行已使用整手、可卖数量和卖出税率。最小报价与涨跌幅先保存为规则信息；实际涨跌停价和停牌状态接入T13/M2，不能仅用普通10%比例推断所有股票、上市初期和除权日。模拟手续费由研究参数单独给定，不能当成所有券商的实际费率。

ETF必须提供已核验类别和有效期；股票ETF、跨境T+1类与允许回转的类别分别处理。未知类别、缺日期、重叠有效期、状态未核验都不能默认可交易。A股按T+1约束。历史主板、科创板、创业板、北交所应各有具体依据，不按证券代码前缀猜测完整制度。当前界面合成例仍允许旧资产/整手假设，结果明确记为`legacy_assumptions`，不能标成经过历史制度校验。

本轮补查了[上交所2026年交易规则及附件](https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260424_10816492.shtml)：公告说明2026-07-06起实施、取代2023年版本，并有暂缓实施条文。附件1的3.1.4–3.1.5区分回转交易，跨境类别也有条件；3.3.8规定竞价买入数量和零股卖出；3.3.11规定报价单位。核对时同时读取了暂缓实施附件，未把大宗交易条文用于本项目日频模拟。

下载证据保存在本机`output/m1-sse-rules-2026.html`与`output/m1-sse-*.txt`。这次核对并不代表深交所、北交所或所有历史时期已经建好正式规则库；T22/T51/T54仍须逐市场、券种和时期接入真实证券规则。新增测试中的规则日期、费率与ETF均为合成样本，不作为制度来源。
