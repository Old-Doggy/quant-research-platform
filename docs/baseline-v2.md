基线回归611项通过，1项既有无效日期解析警告。最初系统临时目录无访问权限，导致54项fixture准备失败；改用项目内输出目录并预先建立父目录后，通过全部测试。未因此修改应用逻辑或跳过测试。

```powershell
New-Item -ItemType Directory -Path output/pytest -Force | Out-Null
./.venv/Scripts/python.exe -m pytest -q --basetemp=output/pytest/<本次唯一目录>
```

`--basetemp`只允许指向本项目专用、可丢弃测试目录；不要指向数据目录或有用文件。Pytest会管理该目录内容。
