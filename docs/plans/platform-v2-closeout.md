## 2. 验收底线和简化边界

### 数据与来源

S01固定实际股票池、市场、起止日、必需字段、价格/收益口径、来源、研究类型和可达图清单。优先复用已有真实样本，不擅自扩大接口限额。当前免费日线仍受最多20只沪深证券、最多一年限制，不能写成全市场能力。

保留新浪、腾讯、BaoStock等已有候选的独立覆盖结论，自动备用仅启用真实核对通过的字段/时段；AKShare包装不算额外上游。东方财富限流时不循环探测。Tushare没有可验证凭据时，展示未配置/未联调，不假装已验权。

行情可浏览和可研究分开。已启用研究区间必须核对真实价格、单位、公司行为、停复牌/缺口和交易限制；缺必需证据则限定区间或禁止研究。browse-only快照不能借筛选跳转绕过门禁。主流程可用合格导入数据或明确标记的合成示例演示，但不能将其称真实研究验收通过。

财务公告时间、首次观察和版本保留；今天抓取旧报表不证明过去可得。缺历史财务/行业/成分时，相应因子和中性化保持禁用。

### 图表和计算不降低标准

- 来源、快照、研究、图形可追溯；缺值/未知不变零，冲突bar不拼接。收益、现金与数量沿用原合同精度；图/表/CSV和逐点保存复算不放宽既有容差。
- 净值/回撤和账本同源，财务存量/流量分开；负值、不完整年、缺口与极值保留，下载全量。旧作品的来源、批次及未通过状态保留。
- 正文目标16px、轴/图例关键文字不低于14px，沿用统一主题；只读选择手形且无可见插入符，真实搜索可输入。文案专业易懂，数据说明低强调且可查。
- 时间图悬停、缩放/平移、重置；选择图可联动详情且有键盘等价入口。所有现有可达图按实际交互要求验收，不给静态图强加无意义点击。
- 所有图形语义在1440宽逐项核对；七工作区和不同布局模板在1024/1280/1440/1920四宽度验收，专有布局另验。复用模板证据，取消“每种情景×四宽度”的机械全排列；共享样式变化重验受影响布局。正常、空数据和缺口仍必验。

### 性能和运行观察

固定机器、环境和样本，复用首调用单列、其后20次计算p50/p95的已有方法。查询、组合切页、参考研究、恢复分别留原始耗时；仅优化定位到的瓶颈，最多两轮。

300ms由硬性发布门槛调整为优化目标，**不是声称当前约494ms已达标**。最终候选相同组合切页场景p95不应比494ms恶化超过20%；固定查询基准热查询p95仍要求<1秒。新增流程记录实际耗时，长操作有状态/取消，不能失去操作入口。不得换小样本、删极值来加速。上一版100证券三年、100MiB恢复、2GiB等新增强制预算取消，不再扩建压力测试工程。

保留**10个连续真实交易日更新观察**，仅覆盖本轮实际启用的行情更新合同，不要求尚未建设的ETF/转债/历史财务服务日更。首日闭环后开始，与研究/页面收尾重叠。休市不计、回放不替代；观察未满时报告“工程验收完成，运行观察待完成”，不能宣称项目最终完成。不自动创建常驻任务或自动化。

## 4. 停止规则和进度报告

1. 每步最小修改→受影响验证→必要入口核对→审查→提交→状态更新。每2–3步检查主链路，工程候选及最终候选做必要全量回归；同版无新问题不重复重跑。
2. 同一根因初验失败后最多两轮修复复验；仍失败记影响、原因和恢复条件，继续独立步骤。不改编号清零轮次，不放宽数值标准。
3. 每个上游/接口/配置最多两批探测；权限错误不重试，临时网络错误每批最多三次退避请求。无新证据即记未启用/等待，不循环探测限流源。
4. 图形满足标准后冻结，性能最多两轮定位优化；不因装饰偏好反复重画，不更换框架，不新增模型。
5. 必需的数据/收益/时点/图形/恢复/授权错误阻止相关能力和最终发布。取消/延期能力不阻塞本轮；已保留必需功能不能静默删掉以通过。
6. 10日观察最多允许一次因故障重开窗口；第二窗口仍失败则停止观察，交付原因及恢复条件。仅数据合同变化才重计受影响窗口，纯样式/文案不重计。不占会话等待自然日，不假设后续会自动执行。
7. 单切片约2小时作拆分参考，连续两个工作段无可验证进展则暂停该项交诊断，继续独立项。不为估算另起大计划。
8. 仅剩真实交易日时可结束当前工程工作段，报告观察待完成；仅剩外部条件或达到修复上限的失败项时，交付缺项/恢复条件后结束本轮。**停止不等于完成。** 所有必需步骤通过并发布后结束，不自行追加优化。

每次交付更新[状态报告](../status-v2.md)与[验收记录](../acceptance-v2.md)：`当前S步骤/状态 → 本次变化和提交 → 真实/合成/页面证据 → 缺项与修复轮次 → 下一步/停止原因`。不按测试数估完成率，不把计划修订算应用交付。
