# 研究结果保存与恢复

结果库位于本机状态目录的 `research_results`，不进入公开作品或公开仓库。每次后台任务使用唯一任务编号；同任务重复提交相同内容可恢复登记，不允许覆盖成另一份结果。

`result_store.py` 保存清单与索引，`result_codec.py` 保存结构和数组。曲线、持仓和账本使用 Parquet；其余值通过显式类型协议保存，包含空值、日期、元组和少量已登记的研究结果类型。不使用 pickle，不根据文件内容动态导入 Python 类。恢复不会运行策略。

数组与清单先写到临时目录，完成校验后原子移入结果目录，最后登记 SQLite 索引。中途失败不产生可读取的成功记录；完整文件已移入但索引失败时，可按同一任务编号重试登记。清单、配置身份、索引与数组 hash 均检查；文件损坏不回落成另一份结果。

首批验证包括真实研究函数生成的合成组合账本：恢复前后逐点精确比较净值、持仓、成交、指标和日期明细。另以独立 Python 进程验证重启读取，检查数组损坏、缺失、清单损坏、配置变更、同任务冲突、写入和索引失败。

本地模式的后台任务已接入自动保存，计算完成后无需等待浏览器轮询。写入、索引或任务日志登记失败均不提交当前结果；日志失败撤回结果索引并保留文件。取消与提交共用锁，取消先到达则不写结果。旧任务数据库自动增加结果引用与经过筛选的失败诊断字段，保留原记录。公开演示模式继续只在内存运行。

“实验 → 已保存结果”按一次运行展示，默认净值与回撤，可切换同一结果的表格并下载；组合账本金额原样保留，绘图副本才除以初始资金。因子结果使用保存的 IC 序列。隐藏的口径核对视图不执行。选坏文件会明确报错，其他记录仍可选，不悄悄切换为旧结果。

实际浏览器运行单股策略后，关闭并重启应用服务，再打开实验页，净值、买入持有、回撤均保留300个点，首末值与重启前一致；对应截图为 `output/playwright/m3-results-restarted.png`。原始输入支持的重新计算随后接入。恢复已保存结果不等于复算；缺少原始输入、旧快照或相同算法版本时，不能宣称复现成功。
