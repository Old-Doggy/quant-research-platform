# 历史股票池与行业

开发版保存证券所属分组、有效起止、公告时间、来源证据和分类版本。生效起日含、退出日不含；退市证券仍在历史主表，查询历史日期时保留，退市之后排除。输入区间重叠或历史覆盖不足会停止查询。

当前成分或月末权重只表示观察当日，覆盖固定为当日；不能把月末成分回填整月，也不能无限前填。历史有效区间必须有相应变更证据；调用者显式声明`verified_historical_intervals`是机制入口，不是程序已经核实该来源的保证。公告只有日期时，查询要求公告早于决策日；同日变更需补充具体可得时间后再支持。

行业查询返回证券到行业的映射、分类版本与缺失证券。同一分类同日一证券多个行业时拒绝；缺失不填“其他行业”，不默认用今天行业作历史中性化。

资料依据为RQData的历史/PIT方法和Tushare[指数成分和权重](https://tushare.pro/document/2?doc_id=96)的月度数据说明。当前只完成服务机制与合成调入/调出/退市/行业迁移检查；真实指数、行业和基准分类适配、日期证据及页面接入仍在T35后续工作中。
