## 运行回归

```bash
python -m pip install -r requirements-dev.txt
python -m pip check
python -m pytest
```

测试使用合成样例和临时目录，不需要行情 token、原研究工作区或账户。下载工具测试使用模拟响应，不会在 CI 中发起行情请求。

GitHub Actions 在 Linux / Windows、Python 3.12 / 3.13 运行同一组回归。测试覆盖字段标准化、质量门槛、指标、信号时序、成本、现金与持仓账本、因子标签、研究状态、曲线读取和七工作区启动。
