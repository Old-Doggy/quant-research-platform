# 固定参数样本外验证

策略运行完成后，在“固定参数样本外验证”中点击“检查样本外稳健性”。当前使用预先固定的参数，不执行模型训练，也不自动挑选表现最好的参数。

时间条按实际交易日排序，依次展示历史上下文、边界剔除、隔离区、验证段、锁定测试段和未成熟尾部。悬停查看准确日期和交易日数，区间表与CSV使用同一分段。默认持有跨度为5个交易日，两个边界分别剔除5日、隔离5日，尾部5日不评分。

“参数与成本”只在验证段运行预设邻域与0/5/10 bp额外滑点；点击热图可查看对应收益与回撤，也可用选择框定位。测试段使用原先指定的参数，按最多63交易日分窗。每个评分窗口从空仓开始，窗口收益不能拼成连续资金账户。负对照用于诊断，不提供独立同分布显著性结论。

页面只绘制正在查看的结果标签。成功报告自动保存到本地实验记录，保留完整切分日期、原始输入和参数；可重新打开图形/表格、下载完整ZIP，在相同计算和依赖版本下重新计算并核对。旧报告缺少日期或输入时只展示其保留内容，不补造可复算依据。

当前范围是固定参数诊断。训练器、自动寻优、任意网格探索、历史行业与真实合格数据的全链路验收仍按M3计划单独完成。
