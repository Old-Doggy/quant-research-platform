# 每日数据更新

当前开发版先提供小范围免费原始日线闭环：BaoStock证券资料/沪深日历、BaoStock与新浪行情、独立核对和版本发布。每次1至20只沪深A股，最长一年；该快照供行情浏览，公司行为、财务时点与历史交易制度未验证时仍不能回测。Tushare下载与参考适配器已实现，账户权限待本机token验证。全市场持续更新仍在M2接入。

先安装可选采集组件：`python -m pip install -r requirements-providers.txt`。本机请求文件不要提交到GitHub，例如：

```json
{
  "root": "D:/quant-local/market-service",
  "symbols": ["600000.SH"],
  "start": "2025-01-01",
  "end": "2025-01-06",
  "dataset_id": "free-a-daily"
}
```

运行`python -m portfolio_app.update_cli --request 请求文件.json --result 结果文件.json`。进程独立于浏览器，原始批次、任务状态和快照保存在root目录。结果文件只记录状态/缺项/版本；失败不替换当前快照。缺日、停牌或两源差异进入待核对，不能用另一份复权行情顶替。

同一数据目录的免费刷新由进程锁保护；页面与命令行同时启动时，后启动者返回`update_busy`，不同时改写任务。页面发起的请求记录在`launches`中，重开页面可以恢复查看；子进程持有运行锁，意外退出且没有结果时显示“任务中断”，不会永久等待。启动保留15秒宽限期。该机制检测进程退出，不检测仍存活进程中的死锁；采集子进程另有超时保护。

更新窗口采用上海时区：08:30检查主表及补抓，09:25后检查因子/约束，18:30抓日线，21:30核对晚间事件。这些是建议窗口，不是数据到齐承诺。当前免费单次入口仍只更新请求文件中明确的日期，不会自动把历史范围滚到今天；全市场调度与按数据类补跑尚在接入。

Windows模板`scripts/register_update_task.ps1`默认仅说明配置，传`-Enable`才注册18:30上海时区任务。此轮未执行启用。模板使用StartWhenAvailable和IgnoreNew，错过时可启动、同任务不重叠；电脑休眠期间不能采集，需开机后补跑。主机时区或夏令时切换后，应重新生成任务触发时间；跨时区长期调度仍需最终验收。停止可在任务计划程序禁用，或使用模板的-Remove。

不要把已发布行情快照当作完整研究数据包。旧版可按snapshot_id读取；回退只改变当前指针，不删旧文件。批次与快照目前不自动清理，避免删掉历史引用；容量保留与恢复按M5统一验收。
