# 可转债观察数据

数据中心 → 可转债，可获取单只转债一年内的日线、最新债券资料和来源转股价调整记录。代码使用 `113052.SH`、`128039.SZ` 格式。原始页面、原始日线和标准结果保存在本地，不进入公开仓库。

## 来源和单位

- 日线：新浪，经 AKShare `bond_cb_daily_sina` 获取；原始价格为元/张，成交量为张，未提供成交额，保持空值。
- 资料：新浪 `bond_cb_profile_sina`，并保留信息页、转股价页与行情页证据。正股仅从页面明确链接提取，缺失时留作待补充。
- 转股价：新浪 `/bond/conversion/{code}.html`，分别保存公告日、生效日、价格和抓取时间。观察记录不能证明抓取前已经掌握这些信息。
- “到期日”是来源当前字段，可能反映提前结束，不能替代原始合同期限。评级也是最新观察资料。

数量单位核对样本为113052.SH在2026-11-11至13日：新浪数量2879620、3717100、4507960张，腾讯287962、371710、450796手，按10张/手一致；收盘112.699、112.715、112.780元一致。此核对不代表完整历史跨源一致，也不用于推造缺失成交额。

## 页面和计算

价格与成交量共用日期轴，悬停读取原始值；转股价用阶梯线展示调整，悬停显示公告日。图表、表格和CSV使用同一保存批次。日线不补结束交易后的价格。

历史查询要求公告与观察均早于信息日期、生效日不晚于估值日期；同一生效日价格矛盾会拒绝查询。转股溢价计算需要同日债券价格、正股价格、有效转股价与面值，当前页面不填造溢价曲线。

## 已核验范围与缺项

真实样本：兴业转债69个观察日及7次转股价记录；南银转债30日及6次记录；三力转债22日及8次记录。后两只保留结束交易样本，没有从主表中删除。

尚未接通完整的强赎、回售、付息、退市结算事件和历史交易制度；正股映射也未覆盖全部样本。当前为观察数据，不作为可执行研究快照。T52–T55完整交付还需要事件覆盖、交易引擎、价格/溢价联动筛选和真实事件区间对账。
